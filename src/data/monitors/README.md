# Monitor Data

Monitor definitions are committed as JSON files and bundled into the Worker at build time.

## Files

- `curated.json` — Hand-curated high-traffic portals checked every 5 minutes (`tier: "critical"`).
- `imported/*.json` — Agency and SUC websites generated by `npm run import:websites` from [bettergovph/bettergov](https://github.com/bettergovph/bettergov) (`tier: "standard"`, checked every 15 minutes).

## Rules

1. Every `slug` must be unique across all files and match `^[a-z0-9-]+$`.
2. Every `category` must exist in `src/data/categories.json`.
3. Never rename an existing `slug` without migrating historical rows in `bgovph_checks`, `bgovph_daily_stats`, and `bgovph_incidents`.
4. Validate changes with `npm run validate:data`.

## Agency Opt-Out

Government portal administrators who wish to adjust a check URL, set a custom `expectedStatus`, or opt out of monitoring can open an issue in this repository.
